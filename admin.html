⚙Configuración inicial

Se hace una sola vez y sirve para todas las computadoras. Después, cada vez que entres a Administración, solo se pide la clave que elijas acá.

¿Qué es el código de GitHub? Es el código largo que empieza con github_pat_ y que guardaron cuando lo crearon.
• Si lo tienen guardado: usen ese mismo. No hace falta crear uno nuevo.
• Solo si lo perdieron: hay que crear uno nuevo en GitHub (cuenta la-peruana → Settings → Developer settings → Fine-grained tokens), con permiso Contents: Read and write sobre e-commerce.

1. Código de GitHub (empieza con github_pat_)

2. Elegí la clave de Administración (mínimo 10 caracteres, con letras y números; que no sea fácil de adivinar, por ejemplo dos palabras y un número)

2Subí el Excel de precios

Podés subir directamente el Excel del MK2 (toma solo la hoja Web), o un Excel con las columnas Categoría, Producto, Precio, Unidad, Descripción, Foto y Activo. Antes de subirlo, guardalo en Excel.

3Revisá los cambios y publicá

📷Subir una foto nueva

La foto se achica sola antes de subirla, para que la tienda cargue rápido en el celular. Después copiá el nombre que aparece en la columna Foto del Excel.
